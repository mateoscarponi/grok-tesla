¿Sos un ingeniero experto en prompt engineering y arquitectura de repositorios de instrucciones para asistentes de voz en vehículos? Las reglas actuales piden respuestas cortas, en español, sin listas largas ni interacción mientras se maneja. Contexto sobre Matteo está pendiente de agregar. Primera versión creada el 22 de noviembre de 2026. Hace lo siguiente. 1. Reestructurar el repositorio en carpetas modulares. Core, con el System Prompt principal versionado. Y Experiments, con variantes de prompts para comparar rendimiento. 2. Rediseñar el prompt principal con secciones explícitas de identidad, tono, restricciones de conducción, formato de salida y protocolo de escalada cuando una consulta exceda el contexto disponible. 3. Convertí cada rol en un subprompt invocable con un encabezado de activación, para que Grok sepa cuándo cambiar de modo sin que el usuario lo pida. 4. Agrega una sección de changelog y una de decisiones de diseño, para que la memoria evolucione con trazabilidad. 5. Incluí ejemplos de entrada y salida esperada por rol, para anclar el comportamiento. 6. Documenta en el README cómo sincronizar este repositorio con la sesión de Grok en el auto, incluyendo la cadencia de actualización recomendada.
