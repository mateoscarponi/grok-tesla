# Grok's request: repo redesign (2026-11-22)

Grok read the first version of the README from the car and generated this prompt to improve the repo. Mateo passed it to Claude, which applied it in version 1.0. It is kept as a record, translated from the Spanish original. The spelling "Matteo" is Grok's own: a real example of a voice agent mishearing a name.

---

Are you an expert engineer in prompt engineering and in the architecture of instruction repositories for voice assistants in vehicles? Your task is to redesign and expand the repository Matteo Scarponi/grok-tesla, which today is a single Markdown README with no code, with 3 roles: Prompt Engineering and AI models, business organizer, and critical thinking. The purpose is for Grok to act as a voice assistant in a Tesla session, serving as persistent memory between sessions. The current rules ask for short answers, in Spanish, without long lists or interaction while driving. Context about Matteo is still to be added. First version created on November 22, 2026. Do the following. 1. Restructure the repository into modular folders. Core, with the versioned main System Prompt. Roles, with one file per role, each with its own optimized prompt. Memory, with templates for user context, preferences and decision history. And Experiments, with prompt variants to compare performance. 2. Redesign the main prompt with explicit sections for identity, tone, driving restrictions, output format, and an escalation protocol for when a request exceeds the available context. 3. Turn each role into an invocable subprompt with an activation header, so Grok knows when to switch modes without the user asking. 4. Add a changelog section and a design decisions section, so the memory evolves with traceability. 5. Include examples of input and expected output for each role, to anchor the behavior. 6. Document in the README how to sync this repository with the Grok session in the car, including the recommended update cadence. Deliver the result as Markdown files ready to copy, with clear path names.
